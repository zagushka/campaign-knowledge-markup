# Интерактивные карточки решений DM

## Цель

Расширить Campaign Knowledge Markup. Плагин должен показывать карточки пакета
решений DM как формы в Obsidian Live Preview. Markdown остаётся единственным
источником данных.

## Область работы

Плагин обрабатывает заметки с маркером:

```markdown
<!-- dnd-packet: schema: v2 -->
```

Карточка начинается с заголовка `### DC-...` и заканчивается перед следующей
карточкой или концом файла. Карточка с `state: draft` доступна для изменения.
Карточки с `state: processed`, `deferred` или `emergent` используют ту же форму,
но все поля в них доступны только для чтения.

Функция работает только в Live Preview. Существующая настройка Preview mode
включает и отключает формы вместе с текущим представлением проверок. Reading
mode и формат пакета не меняются.

## Представление

Форма заменяет всю карточку и показывает:

- заголовок и идентификатор карточки;
- вопрос и строку контекста;
- 2–4 обычных варианта;
- пометку рекомендации;
- поле уточнения или своего ответа;
- варианты «Решить позже» и «Не определять заранее»;
- поле события или владельца для каждого из этих двух вариантов.

Служебные HTML-маркеры и технические поля скрыты. Завершённая карточка также
показывает итог обработки, если он есть. Стили используют переменные темы
Obsidian и не задают отдельную цветовую схему.

## Изменение Markdown

Каждое действие сразу создаёт транзакцию редактора:

- выбор обычного варианта снимает выбор со всех других вариантов;
- повторный клик по выбранному варианту оставляет карточку без выбора;
- обычный вариант можно дополнить своим ответом;
- текст своего ответа без обычного варианта является полным ответом;
- выбор «Решить позже» или «Не определять заранее» снимает обычный выбор и
  очищает свой ответ;
- ввод своего ответа снимает выбранный вариант отсрочки;
- текст события или владельца записывается после двоеточия в строке выбранного
  варианта отсрочки.

Плагин меняет только строки выбранных флажков, содержимое блока ответа и текст
вариантов отсрочки. Идентификаторы, источники, рекомендации, состояния и другие
маркеры остаются без изменений. Виджет сохраняет фокус поля при каждой записи.

## Безопасность

Перед записью плагин снова находит карточку по её идентификатору в текущем
состоянии редактора. Если карточка исчезла или её структура стала некорректной,
плагин не записывает данные и показывает уведомление.

Если заметка или карточка не соответствует схеме `v2`, плагин оставляет
исходный Markdown. Существующее представление проверок продолжает работать без
изменений.

## Файлы

- `main.js` — разбор карточек, виджет Live Preview и запись изменений;
- `styles.css` — форма и состояния только для чтения;
- `test.js` — небольшие проверки разбора и изменения Markdown;
- `package.json` — команда проверки;
- `README.md`, `manifest.json`, `versions.json` — документация и версия.

Новые зависимости и сборщик не нужны.

## Проверка и доставка

Автоматическая проверка должна подтвердить:

- разбор активной и завершённой карточки;
- взаимное исключение обычных вариантов;
- сохранение своего ответа;
- выбор каждого варианта отсрочки;
- запрет записи в завершённую карточку;
- сохранение исходного Markdown при ошибке разбора;
- корректный синтаксис `main.js`.

После автоматической проверки обновляется установленная копия плагина в vault.
Затем выполняется проверка в Obsidian. Изменения отправляются в GitHub только
после успешных проверок.
